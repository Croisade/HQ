# overseerr

Status: Retired

Host: [homelab-server](../homelab-server/README.md)

Replaced by [jellyseerr](../jellyseerr/README.md) — Overseerr's request-management features only work against a Plex or Emby media server, and this lab standardized on Jellyfin instead. Jellyseerr is the Jellyfin-compatible fork of this same project, so the swap was a drop-in replacement (`requests.thegarden` carried over unchanged).

Container stopped and removed; `data/` kept here for history, not deleted.
